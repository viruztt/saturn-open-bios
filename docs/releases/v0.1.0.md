# SaturnOpenBios v0.1.0

The first release: an open, clean-room BIOS that boots every game I own and
have tried on MiSTer, with CD music and working saves.

## Download

`saturn-open-bios-v0.1.0.zip` contains:

- `boot.rom` - the BIOS (512 KB)
- `boot-diag.rom` - the same with diagnostics pages, for bug reports
- `README.txt`, `COPYING` (GPL-2.0-or-later), `SHA256SUMS`

## Installing on MiSTer

1. Copy `boot.rom` to the SD card as `games/Saturn/boot.rom` (keep a copy of
   the one you have).
2. Load the Saturn core again (a reset is not enough), then load a game.
3. For CD music use CHD images, or cue sheets without a `PREGAP` line.
4. For saves to survive power-off, turn **Autosave** on in the core's OSD.

## What's in it

- Boots Saturn discs on MiSTer and in emulators (Kronos, Yabause), with
  CD audio; the hardware is left the way games expect, checked against the
  original on MiSTer.
- System calls: SCU interrupt dispatch running from Work RAM, SH-2 and SCU
  vectors, priorities and masks, semaphores, clock change, and the "load
  CD" calls used by boot loaders.
- Backup RAM for the internal memory and backup RAM cartridges; blank
  internal memory is formatted at boot.
- Backup RAM manager (delete, copy, format) and a settings page
  (language, clock): tap **Start** during the boot screen, or boot with no
  disc.
- Cartridge boot for Action Replay style ROM carts (Pseudo Saturn Kai
  Lite).
- A dark red boot screen with a progress bar and the version shown on
  screen.

## Tested games (MiSTer)

Clockwork Knight, Die Hard Arcade, The House of the Dead, Panzer Dragoon,
Shutsudo! Minisuka Police, Sonic R, Virtua Cop, Virtua Cop 2: all play,
with CD music.

## Known limitations

No audio CD player, no Video CD / Photo CD, no floppy drive, no
stereo/mono setting, and no Pseudo Saturn Kai cheat codes (its cheat loader
calls into Sega's BIOS). Not tested on a real Saturn. See the README for
the full list.
